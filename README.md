# Advanced Coder.ddev.com Usage

A [reveal.js](https://revealjs.com/) presentation on using [coder.ddev.com](https://coder.ddev.com): Drupal contribution, workspace access, the freeform template, and Claude Code.

**Slides:** <https://rfay.github.io/advanced-coder-presenatation>

## Run Locally

```bash
npm install
npm start
```

This serves the presentation at <http://localhost:8000>.

Slide content is in [slides/advanced-coder-presenatation.md](slides/advanced-coder-presenatation.md). Pushing to `main` deploys to GitHub Pages.
